## 🎲 Featured Game — Dice Crusaders
<p align="center">
  <img src="https://woonabin.github.io/MaribinStudio/images/dice-crusaders-banner.png" width="480" alt="Dice Crusaders Banner"/>
</p>

> [ 현재 개발 중 ]
> **Dice Crusaders (주사위 기사단)** 는 주사위를 굴려 영웅의 운명을 결정하는 전략 RPG입니다.  
> 각 영웅은 개성 있는 주사위 세트를 지니며, 주사위 눈의 조합으로 **스킬 발동 / 크리티컬 / 연계 공격**이 결정됩니다.  
> 매 판이 예측 불가능하면서도 치밀한 전략으로 가득합니다.

### ⚔️ 특징
- **픽셀 스타일 전투** : 클래식 감성과 현대적 이펙트를 결합  
- **전략적 주사위 시스템** : 모든 선택이 승패를 바꾼다  
- **다양한 영웅 클래스** : Tank, Knight, Archer, Mage, Healer  
- **Cross-Platform** : iOS / macOS / Windows 지원  
- **Firebase 기반 데이터 관리** 및 **클라우드 세이브**  

> 🔗 [Dice Crusaders 공식 홈페이지](https://woonabin.github.io/MaribinStudio/dice-crusaders.html)
