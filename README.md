## About

**Maribin Studio**는 1인 인디 스튜디오입니다.  
클래식 아케이드 감성의 게임과, 현장(방송실)에서 바로 쓰는 유틸을 함께 만듭니다.

| Focus | Notes |
|:------|:------|
| Games | Unity · pixel art · dice / tactics |
| Tools | Broadcasting suite · Stream Deck · Unity modules |

## Featured

### DiceQuest / Dice Crusaders
주사위 조합으로 스킬·크리티컬이 갈리는 픽셀 전투.  
→ [`DiceQuest`](https://github.com/WooNaBin/DiceQuest) · [`dicecrusaders`](https://github.com/WooNaBin/dicecrusaders)

### Broadcasting Suite
방송실 스케줄 · 일지 · 파일체크 · HyperDeck 제어를 **한 모노레포**에서.  
→ [`broadcasting-suite`](https://github.com/WooNaBin/broadcasting-suite)

### Maribin Unity Modules
UI · SoundManager 등 UPM 유틸 모노레포.  
→ [`MaribinUnityModules`](https://github.com/WooNaBin/MaribinUnityModules)

### Stream Deck
Maribin Home / Studio용 Stream Deck 플러그인.  
→ [`streamdeck-plugins`](https://github.com/WooNaBin/streamdeck-plugins) · [`streamdeckplugin-maribinhome`](https://github.com/WooNaBin/streamdeckplugin-maribinhome)
